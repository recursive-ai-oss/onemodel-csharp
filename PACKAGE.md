# RecursiveAI.OneModel

A neural-network runtime for .NET in pure managed C#: ONNX import, graph optimization and SIMD CPU kernels, with no native binaries and no dependency beyond the shared framework.

This is a preview; the package currently contains only the project skeleton. Source, issues and documentation: <https://github.com/recursive-ai-oss/onemodel-csharp>.
